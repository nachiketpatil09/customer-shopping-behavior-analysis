# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

**Customer Shopping Behavior Analysis** is a data analytics project focused on analyzing customer purchasing patterns using transactional data.

The project analyzes **3,900 customer purchase records across 18 attributes** to understand customer spending behavior, product preferences, customer segments, discount usage, shipping preferences, and subscription behavior.

The objective is to transform raw transactional data into meaningful business insights that can support **customer retention, subscription growth, product strategy, and targeted marketing decisions**.

---

## 🎯 Business Objectives

The key objectives of this project are to:

- Analyze customer purchasing and spending patterns
- Identify high-value and repeat customers
- Understand customer preferences across product categories
- Analyze the impact of discounts on purchasing behavior
- Compare subscribers and non-subscribers
- Segment customers based on purchase history
- Identify top-performing products and categories
- Analyze revenue contribution across different customer age groups
- Build an interactive dashboard for business reporting

---

## 🗂️ Dataset

The dataset contains **3,900 purchase records and 18 columns**.

### Key Data Categories

**Customer Information**
- Age
- Gender
- Location
- Subscription Status

**Purchase Information**
- Item Purchased
- Category
- Purchase Amount
- Season
- Size
- Color

**Shopping Behavior**
- Discount Applied
- Promo Code Used
- Previous Purchases
- Frequency of Purchases
- Review Rating
- Shipping Type

The dataset initially contained **37 missing values in the Review Rating column**.

##  1. Data Analysis & Cleaning Using Python

Python and Pandas were used to prepare the dataset for further analysis.

### Key Activities

- Loaded the dataset using Pandas
- Explored the dataset using `info()` and `describe()`
- Identified missing values
- Imputed missing Review Rating values using the **median rating of each product category**
- Standardized column names using **snake_case**
- Created an `age_group` feature by grouping customer ages
- Created a `purchase_frequency_days` feature
- Checked data consistency between discount and promotional-code fields
- Removed the redundant `promo_code_used` column
- Connected Python with PostgreSQL and loaded the cleaned dataset into the database



---

## 🗄️ 2. SQL Analysis Using PostgreSQL

The cleaned data was loaded into PostgreSQL for structured business analysis.

### Business Questions Analyzed

1. Revenue generated by male and female customers
2. High-spending customers who used discounts
3. Top 5 products based on average review rating
4. Average purchase amount by shipping type
5. Subscribers vs. non-subscribers
6. Products with the highest percentage of discounted purchases
7. Customer segmentation based on purchase history
8. Top 3 products within each category
9. Relationship between repeat purchases and subscription status
10. Revenue contribution by customer age group

## 👥 3. Customer Segmentation

Customers were classified into three segments based on their purchase history:

- **New Customers**
- **Returning Customers**
- **Loyal Customers**

This segmentation helps understand customer purchasing behavior and provides a foundation for developing targeted customer-retention strategies.

### 🏷️ Discount Strategy
Review discount policies to balance increased sales with margin control.

### 🛍️ Product Strategy
Promote highly rated and frequently purchased products in marketing campaigns.

### 🎯 Targeted Marketing
Focus marketing efforts on high-revenue customer age groups and relevant shipping/customer segments.
